#  linux command practice 

## process mangement commands
- ps  : shows running process
- ps aux : shown all running process
- top : live view of process cpu &ram
- htop : Interactive process monitor
- pgrep : find process by name
- pidof : find PID of a program
- kILL : stops a process using PID
- KiLL all : stops process by name
- nice : start process with priority
- renice : change priority of running process
- jobs : shown background jobs
- bg : send stopped job to background
- fg : Bring background job to foreground
- nohup : keep process running after logout

## Linux file system commands
- pwd : shows current directory
- ls : lists file /folder
- ls -l : detailed file information            
- ls -la : shown hidden files too                 
- cd : change directory
- mkdir : create a directory
- touch : create an empty file
- cp : copies file folder
- mv : moves or rename file
- rm : delete a file
- rm -r : delete a directory
- cat : display file content
- less : read large file page by page
- head : shown first line
- tail : shown last line
- find : search for file
- du : shown directory / file size
- df : shown disk space
- file : identity file system
- stat : show detailed file

## easy way to remember
 - Navigate : pwd ,ls,cd
 - create : mkdir,touch
 - copy/move : cp , mv
 - Delete : rm
 - read : cat,less,head,tail
 - search : find
 - storage : df,du
 - Details : start,file

  ## network troubleshooting commands
  - ip addr : shown ip address
  - ip route : shown routing table
  - ping : check network connectivity
  - traceroute : path to destination
  - ss : shown network connection
  - curl : Test HTTP
  - nslookup : check DNS resolution
  - dig : details DNS information
  - hostname : shown system hostname
  - ip link : shown network interface
